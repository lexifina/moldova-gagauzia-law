# Vulnerabilities in the law of Gagauzia

The vulnerability detectors from [lexifina/global-law](https://github.com/lexifina/global-law/tree/main/vulnerabilities) look for mechanical mistakes in legislation: a rule applying "until" a date that has passed, a provision repealed before its replacement took effect, two amendments to the same provision on the same day, a rule in force before it was published.

This folder is a placeholder: the detectors have not been run on this repository yet. When they are, the results will go here as in [serbia-law's vulnerabilities/](https://github.com/lexifina/serbia-law/tree/main/vulnerabilities): the flags by category, the strongest ones reviewed by a model, each surviving case checked by hand, and the data and scripts behind them.

A flag will be a prompt to look, not legal advice.
