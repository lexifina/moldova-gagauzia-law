# Статья 80. Решения судебных инстанций по жалобам.
(1) Решения судебных инстанций по жалобам могут быть обжалованы в соответствии с Гражданским процессуальным кодексом.
(2) Вступившие в законную силу решения судебных инстанций обязательны для исполнения с момента их принятия.
