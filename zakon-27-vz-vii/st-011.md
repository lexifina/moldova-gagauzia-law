# Статья 11.
(1) Трансферты специального назначения из государственного бюджета для финансирования инфраструктуры автомобильных дорог районного значения, предусмотренные для центрального бюджета в сумме 21 780,4 тыс. леев, используются для финансирования инфраструктуры автомобильных дорог районного значения, администрируемых на региональном уровне.
(2) Трансферты специального назначения для финансирования инфраструктуры местных автомобильных дорог общего пользования, предусмотренные для бюджетов примэрий в сумме 39 976,5 тыс. леев используются исключительно для инфраструктуры коммунальных дорог и улиц.
