# Статья 64. Решения, принимаемые в результате обсуждения проекта закона во втором чтении
В процессе обсуждения проекта закона во втором чтении Народное Собрание принимает одно из следующих решений:
принять закон;
одобрить проект закона во втором чтении и подготовить его для рассмотрения в третьем чтении.
(2) Проект закона, одобренный во втором чтении, направляется в ответственную комиссию для подготовки его к рассмотрению в третьем чтении по поступившим поправкам.
