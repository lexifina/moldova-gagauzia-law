# Статья 95. Депутатское расследование
По инициативе рабочих органов Народного Собрания, а также по инициативе не менее одной трети от числа избранных депутатов Народное Собрание большинством голосов избранных депутатов может назначить депутатское расследование.
Для проведения депутатского расследования из числа депутатов создается специальная комиссия. Все органы власти и должностные лица обязаны оказывать необходимое содействие работе комиссии, беспрепятственно представлять необходимые для объективного изучения вопроса сведения и документы. Специальная комиссия вправе вызывать на свои заседания для дачи объяснений любое должностное лицо.
Результатом расследования является мотивированное заключение специальной комиссии, которое доводится до сведения депутатов Народного Собрания.
По результатам расследования Народное Собрание принимает соответствующее постановление.
