# Статья 191. Бюллетень для голосования
(1) В бюллетень для голосования включается текст вопроса, выносимого на местный референдум. Справа от текста вопроса или законопроекта размещаются горизонтально два прямоугольника с вписанными в них словами «ЗА» и «ПРОТИВ», а под ними по кружку.
(2) В случае вынесения на местный референдум нескольких вопросов для каждого из них составляется отдельный бюллетень. При проведении одновременно нескольких референдумов, а также в случае одновременного проведения референдума и местных выборов бюллетени для голосования должны различаться по цвету.
(3) Бюллетени для голосования оформляются в соответствии со статьей 16 Уложения Гагаузии и положениями закона АТО Гагаузия (Гагауз Ери) «О функционировании языков на территории Гагаузии (Гагауз Ери)».
(4) Бюллетени для голосования печатаются в количестве, соответствующем числу лиц, внесенных в списки избирателей, с резервом в один процент.
(5) Бюллетени для голосования должны быть одинаковы по формату, отпечатаны одним и тем же шрифтом, на бумаге одного цвета и одинаковой платности.
(6) Образец бюллетеней для голосования, протоколов избирательных советов, протоколов участковых избирательных бюро по проведению местного референдума утверждается Центральной избирательной комиссией Гагаузии, а текст бюллетеней для голосования — окружными избирательными советами.
(7) Бюллетени для голосования передаются Центральной избирательной комиссией окружным избирательным советам за два дня, а участковым избирательным бюро за один день до дня референдума.
