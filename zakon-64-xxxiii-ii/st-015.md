# Статья 15. Присвоение винам и другим продуктам виноделия наименования по месту происхождения
Наименование по месту происхождения присваивается натуральным винам и другим продуктам виноделия, обладающим особенными качественными характеристиками, обусловленными особенностями местности и оригинальной технологией их приготовления в соответствии с Регламентом производства вин с наименованием по месту происхождения, утвержденным Исполкомом Гагаузии.
