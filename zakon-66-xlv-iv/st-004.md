# Статья 4.
Закладка виноградных насаждений для производства товарного винограда, используемого для получения вина «vin ţărănesc»(«çіftçі şarabı»), осуществляется только сортами винограда, зарегистрированными в Регистре сортов растении. В случае, если площадь виноградных насаждений превышает 0,5 гектара, закладка плантаций осуществляется на основе соответствующего проекта, разработанного лицензированными юридическими или физическими лицами (проектными бюро), которые несут ответственность за качество разработанных проектов согласно действующему законодательству.
