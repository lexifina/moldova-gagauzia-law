# Статья 19.
Запрещается реализация вина «vin ţărănesc»(«çіftçі şarabı ») без сертификата на соответствие, выданного органами по сертификации на основании протокола испытания, выданного ЦГТМ г. Чадыр-Лунга. Сертификация данного вида продукции, исходя из небольших объёмов его производства и реализации, осуществляется по льготным тарифам.
