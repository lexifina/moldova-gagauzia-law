# Статья 46. Покрытие балансовых убытков
(1) Балансовые убытки прошлых лет кооператива покрываются за счет его текущей чистой прибыли, затем из других фондов, определенных уставом кооператива.
(2) Если средств, указанных в части (1), недостаточно для покрытия балансовых убытков прошлых лет, по решению общего собрания для этой цели используются средства из фондов, предусмотренных статьей 48.
