# Статья 48. Общие принципы систематизации законодательных актов
(1) Систематизация законодательных актов представляет собой их организацию по определенным критериям с целью облегчения пользования нормами права и обеспечения их единообразного применения.
(2) Основными формами систематизации законодательных актов являются:
а) инкорпорация, представляющая собой простую систематизацию актов по хронологическому, алфавитному принципу, по отраслям права, правовым институтам и т.п.;
б) кодификация, представляющая собой более сложную, на основе единой концепции, систематизацию норм права, относящихся к отдельной отрасли права, осуществляемую путем объединения их в кодексы.
