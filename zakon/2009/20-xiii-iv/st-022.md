# Статья 22. Контроль за выполнением плана действий
(1) Контроль за выполнением плана действий по реализации программ развития Гагаузии в процессе ее реализации осуществляется Исполнительным Комитетом Гагаузии.
(2) По итогам выполнения плана действий по реализации программ развития Гагаузии начальник соответствующего уполномоченного отраслевого управления Исполнительного Комитета Гагаузии ежегодно отчитывается на заседании Исполнительного Комитета Гагаузии по итогам которого принимается Постановление Исполнительного Комитета Гагаузии.
(3) По итогам плана действий по реализации программ развития Гагаузии Глава (Башкан) Гагаузии (Гагауз Ери) представляет в Народное Собрание Гагаузии окончательный отчет о выполнении программы развития Гагаузии одновременно с проектом программы развития Гагаузии на следующий период.
