# Статья 7. Правила взаимоотношений депутатов с работниками аппарата Народного Собрания Гагаузии
(1)Депутат взаимодействует с сотрудниками аппарата Народного Собрания Гагаузии для выполнения депутатских обязанностей в строгом соответствии с законодательством
(2)Деятельность аппарата Народного Собрания Гагаузии направлена на обеспечение исполнения депутатом своих полномочий. Сотрудники аппарата способствуют установлению профессиональных, конструктивных отношений с депутатами, что является важным фактором эффективной деятельности Народного Собрания Гагаузии.
(3)Депутат при взаимодействии с работниками аппарата Народного Собрания Гагаузии, призван показывать пример деловитости, способствовать формированию профессиональных взаимоотношений.
