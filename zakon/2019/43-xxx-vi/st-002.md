# Статья 2.
Предоставить Исполнительному Комитету Гагаузии право изменять показатели бюджета с последующим утверждением Народным Собранием Гагаузии, в случае увеличения объема трансфертов, имеющих целевое назначение, связанное с внедрением закона о единой системе оплаты труда в бюджетной сфере, из государственного бюджета Республики Молдова в центральный бюджет АТО Гагаузия.
